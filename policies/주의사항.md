# Order & Refund v0.5 데이터 묶음

이 디렉터리는 서로 다른 신뢰 경계를 가진 네 종류의 파일을 포함합니다.

- `shop.db`: 고객·주문·상품·배송·환불의 정책 원천 데이터베이스입니다.
- `agent_cases.json`: 평가받는 Agent에게 제공할 수 있는 질문·대상 ID·요청 정보입니다. 정답 필드는 없습니다.
- `test_cases.json`: 20개 내부 평가 사례와 전체 PolicyFacts·DecisionResult를 담은 Gold 원장입니다.
- `answer_key.db`: `test_cases.json`과 같은 Gold를 조회하기 위한 별도 SQLite 데이터베이스입니다.

## 접근 경계

평가받는 Agent에는 `shop.db`와 `agent_cases.json`만 읽기 전용으로 제공합니다. `answer_key.db`, `test_cases.json`, `policies/policy_oracle.py`는 Agent의 파일 권한·모듈 경로·네트워크에서 차단해야 합니다. 저장소가 공개되어 있다는 사실만으로 실행 격리가 생기지는 않으므로 Testbed 실행기가 이 경계를 강제해야 합니다.

`answer_key.db`와 `test_cases.json`은 현재 `CANDIDATE_PENDING_INDEPENDENT_HUMAN_REVIEW` 상태입니다. GOLD-10 시나리오 표와 Oracle의 교차 확인은 완료했지만 별도 사람 검토자가 승인하기 전에는 최종 baseline으로 표시하지 않습니다.

## 재생성

저장소 루트에서 다음 명령을 실행합니다.

```bash
python data/build_answer_data.py
python -m unittest discover -s tests -p 'test_*.py'
```

생성기는 현재 시각·환경 변수·네트워크를 사용하지 않습니다. 버전과 SHA-256은 `artifacts/version_manifest.json`에 기록됩니다.
